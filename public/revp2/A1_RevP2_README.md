# A.1 / Rev.P2 — Exterior Coordination & Visual QA

## Основные файлы

- `20_Модель_A1_RevP2_ExteriorQA.glb` — очищенная и детализированная наружная модель для просмотра и презентации. Подземные сети исключены.
- `20_Модель_A1_RevP2_Coordination.glb` — полная координационная модель с инженерными сетями.
- `20_Модель_A1_RevP2_ExteriorQA.obj` — обменный формат наружной модели.
- `20_Exterior_QA_Report.html/json` — повторный аудит.
- `20_Ведомость_исправлений_RevP2.csv` — реестр изменений.

## Статус

Функциональная посадка А.1 сохранена. Исправления относятся к дорогам, террасам, подпорным стенам, наружному благоустройству, ограждениям, резервным зонам и визуальной координации. Модель остается в локальной системе координат и требует перепривязки после получения съемки 1:500.
